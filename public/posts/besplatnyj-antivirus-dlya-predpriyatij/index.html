Бесплатный антивирус для предприятий

17 января 2015 2 мин чтения 258 слов
it soft bezopasnost
⚠ Этой статье больше 11 лет. Информация может быть устаревшей.

Работая в сфере информационных технологий, многие (если не каждый) сталкивались с вопросом о выборе антивирусного программного обеспечения. Вопрос можно считать довольно серьезным, особенно, если учитывать специфику - вы находитесь не возле своего домашнего компьютера.

Работа организаций (пусть даже маленьких) четко регламентирована законом, поэтому поставив бесплатный антивирус на компьютер пользователя вы должны точно знать, разрешает ли вам это закон.

Многие считают, что Бесплатный антивирус для предприятий  - миф, о существовании которого мечтают любители “халявы”.  И в этом есть смысл - на самом деле антивирусная защита на предприятии вовсе не дешевое удовольствие, которое зачастую (при наличии внушительного парка компьютеров) обходится организации в большую такую копеечку. Бывают так же ситуации, когда действующая лицензия закончилась, а защита на ПК нужна, т.к. пользователь запросто может что-нибудь поймать.

На данный момент существует несколько решений, которыми можно воспользоваться на совершенно законных основаниях :

  • Microsoft security essentials
  • Comodo Internet Security
  • Nano antivirus
  • Immunet free antivirus

Microsoft security essential организация покупает вместе с лицензией на Windows - не стоит забывать об этом.

Comodo Internet Security добрые дяди отдают вам совершенно бесплатно (при этом все время напоминая о том, что есть решения и по лучше, но обойдутся они вам в копеечку).

Nano antivirus в виду своего возраста (это мое мнение) отдают совершенно бесплатно всем желающим им пользоваться, главный офис компании- разработчика находится в Брянске.

Immunet free antivirus - бесплатный антивирус для предприятий (и дома в том числе), разрабатывается в Америке и на данный момент считается одним из самых легковесных, подробную инфографику можно будет увидеть ниже.

Стоит отметить, что Microsoft security essentials можно законно установить только на 10 ПК.
