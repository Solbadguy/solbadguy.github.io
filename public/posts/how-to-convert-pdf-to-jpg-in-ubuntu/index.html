How to Convert PDF to JPG in Ubuntu

7 января 2018 1 мин чтения 170 слов
howto linux komandnaya-stroka
⚠ Этой статье больше 8 лет. Информация может быть устаревшей.

Очень простой и удобным метод конвертирования изображений из PDF в JPG.  В качестве альтернативы можно рассмотреть пакет imagemagick, но на момент написания статьи он не совсем верно обработал выходные изображения.

В данной заметке я предлагаю использовать утилиты из пакета Poppler, которые, наоборот, справились на 5+.

Производим установку из терминала:

sudo apt-get install poppler-utils

Простейший пример конвертации PDF в JPG:

pdftocairo -jpeg "имяфайла.pdf"

И немного о ключах:

-png
Создает PNG-файл(ы)

-jpeg
Создает файл(ы) JPEG

-tiff
Генерирует TIFF-файл(ы)

-f
Задает первую страницу для преобразования.

-l
Задает последнюю страницу для преобразования.

-о
Создает только страницы с нечетными номерами.

-e
Создает только четные страницы.

-r
Определяет разрешение "печати". Значение по умолчанию - 150 PPI.

-mono
Создайте монохромный файл (только PNG и TIFF).

-gray
Создайте файл в оттенках серого (только PNG, JPEG и TIFF).

Приведем их к целевому размеру:

convert *.jpg -resize 171 resize-171.jpg - приведем все картинки к ширине 171, высота при этом будет расчитана автоматически.

convert *.jpg -resize x274 resize-274.jpg - приведем все картинки к высоте 274, ширина при этом будет расчитана автоматически.
